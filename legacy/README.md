# Historical implementations

These files are retained for research provenance and are not imported by the active Flask application.

- llama2.py: original alternative pipeline, including its report.txt ingestion path.

Their contents are preserved. Run historical scripts from the repository root if their relative file paths are needed. The current generation/retrieval code is ../rag_pipeline.py; the application entry point remains ../page.py.
